Фильтрация наблюдений

Проверьте измерения, сравните рабочий расчёт с официальным и сохраните результат в Excel. Фильтры применяются к рабочей копии.

Источник данных

CSV в UTF-8, JSON или XLSX, до 12 МиБ. В Excel ищем первую таблицу со столбцом datetime.

До 60 000 исходных строк в детальной книге.

Фильтры рабочей копии

Задайте рабочий диапазон выбранного параметра. Пустое поле использует стандартную границу. Флаги качества проверяются при любом диапазоне.

Дополнительные проверки

Включайте проверки по отдельности. Пустой порог оставляет стандартное значение.

Для направления ветра учитывается переход через 360°. Поиск временных аномалий пропускает записи со скоростью ветра 0 м/с.

    Как считается покрытие

    Для Кр1 и Кр2 нужно не меньше 18 разных часов с пригодными измерениями. Например, при покрытии 15 из 18 необходимых часов сутки считаются неполными. Для АМЕ-60 нужно не меньше 72 разных сроков.

    Целый календарный месяц проходит проверку, если неполных суток не больше 10, а подряд не больше четырёх. Для части месяца показано только покрытие выбранного периода.

    Покрытие, среднее, минимум и максимум рассчитываются по принятым измерениям. Оценки приведены отдельно.

    Что сохраняется в Excel

    На листе «Сроки» сохраняются дата и время, источник, номера строк, исходные столбцы, рабочее значение, решение алгоритма, официальный статус, причины с флагами и оценка с источником. Суточная и месячная сводки фиксируют результаты расчёта на момент выгрузки.

    В листе «Управление» можно вернуть все исходные значения или исключить их массово. В режиме «По алгоритму» столбец «Режим строки» позволяет вернуть, исключить или заменить отдельное значение оценкой. Зелёный цвет отмечает принятое исходное значение, красный — исключённое.

    Отдельно можно скачать копию исходной книги с отметками рядом с обработанными значениями.
