    Историческая проверка

    Средняя абсолютная ошибка (MAE) в °C. Для правила «как сегодня» прогноз равен последней суточной температуре.

    Как работает модель

    Для расчёта модель использует две суточные средние температуры воздуха выбранной станции и сезонный признак по дате прогноза и широте из паспорта станции. Если широта не указана, сезонная поправка равна нулю.

    Для исторических дат выбирается версия модели, обученная до даты расчёта. В проверке переноса целевая станция исключена из обучения. Ошибки модели и правила «как сегодня» рассчитаны на одних и тех же днях с пригодными наблюдениями.
