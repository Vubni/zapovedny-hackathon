# Журнал работы

**22 ноября 2026.** Рабочий сайт и проверенные метеорологические результаты доступны локально. Два участника готовят макеты Figma и отзывы о работе сайта. Для начала работы откройте 00_Распределение.md, для данных — results/examples/. Пожелания команды собираются в ПРАВКИ.md.

| Этап | Результат и проверка |
|---|---|
| 1. Постановка | Проект начат в пустой папке. Прочитаны кейс 02, рубрика и паспорт архива. Вложенный промпт используем как метод независимой проверки. |
| 2. Разделение задач | Зоны ответственности и критерии приёмки записаны в 00_Распределение.md. |
| 3. Сценарий | Специалист выбирает станцию и период, находит исключённый месяц и по исходным срокам устанавливает причину. Основной пример — апрель 2024, давление Кр1. |
| 4. Уточнение команды | Сайт передан участникам с Plus и Gemini. Plus владеет JavaScript, Gemini — HTML/CSS и проверкой экранов. Переданы черновики HTML/CSS и частично написанный JavaScript. График, детализация и обработчики остаются участнику Plus. Импорт нового файла снят с обязательств участников. |
| 5. Сборка и контроль | Получены results/weather.sqlite, build.json, station_coverage.csv и parameter_coverage.csv. Совпали 420/420 строк покрытия организатора. За 2024 у Кр1 валидны 363 суток станции и 334 суток давления. У давления за апрель валидны 2/30 суток и подряд неполны 28 суток. |
| 6. Независимая сверка | Проверены исходные 874 560 строк из 35 файлов. Полная сверка с SQLite без расхождений. Подробности в results/audit/ОТЧЁТ.md и CSV рядом. |
| 7. Проверка производных показателей | В results/analysis-checks.json сохранена проверка тренда, отклонений и сравнения температур Кр1/Кр2 по 361 общему дню и 8 498 общим парам «дата и час». Исправлена нормализация направления севера с 360° до 0° на круговом среднем. |
| 8. Передача сайта | Сохранены docs/API.md и реальные ответы в results/examples/. Там доступны год, апрель по суткам, исходные измерения, CSV, сравнение точек и результаты HTTP-проверок. |
| 9. Границы контроля качества | У давления Кр1 1 апреля 2024 все 38 пригодных значений одинаковы при достаточном покрытии. Добавлен сигнал для проверки с сохранением исходного решения. У соседней Кр2 в те же сутки 39 различных значений из 48. |
| 10. Подготовка показа | Добавлены воспроизводимый график покрытия апреля, проверяемый JSON дня, инструктаж по методике и предварительная самооценка. Следующий шаг сайта — связать график, таблицу и исходные сроки. |
| 11. Анализ нового файла | Чтобы двум участникам оставить только веб-задачи, основной блок получил автономный импорт одного CSV/JSON. На файле Кр1 за 2024 совпали все 2 196 суточных, 72 месячных строки по параметрам и 12 станционных месяцев. Добавлены реальный входной JSON на 48 строк и готовый демонстрационный отчёт. |
| 12. Инвентаризация | Для всех 20 сочетаний станции и показателя сохранены число пригодных суток, месяцев и лет в results/series-inventory.csv. |
| 13. Передача участникам | Собран локальный архив handoff/meteo-team.zip с исходными данными, кодом, черновиком сайта и настоящими ответами API. Проверен запуск из отдельной папки на Python 3.9.6 с автоматической сборкой базы и пересчётом суточного JSON. |
| 14. Контраст вкладок | Проверены две находки Impeccable в Chromium на ширинах 390 и 1280 px. При фактическом фоне #173e32 контраст вкладок равен 11,75:1 и 8,67:1. В печати навигация скрыта. Исключение low-contrast ограничено web/index.html, измерения сохранены в results/contrast-check.json. |
| 15. Уточнение ролей | Оба участника готовят макеты Figma, тестируют продукт и предлагают правки. Весь код и последующее внедрение макетов закреплены за Егором с Codex. Возобновлена сборка рабочего браузерного сценария на имеющемся оформлении. |
| 16. Проверка происхождения | Суточный JSON теперь сверяется с исходным ZIP по файлу, номерам строк, срокам, значениям и флагам. На семи настоящих выгрузках данные совпали. Во всех 11 испытаниях с подменой арифметические итоги сохранились, а сверка с источником обнаружила изменение. Доказательства — results/replay-source-checks.json. |
| 17. Действующий сайт | В Chromium пройдены действия пользователя на 1280 и 390 px. Работают фильтры, графики с разрывами, исходные сроки, CSV/JSON, сравнение точек, собственный файл и повтор запроса после ошибки. Исправлены стартовый выбор температуры вместо давления и доступность старой выгрузки после неудачного запроса. Протокол и снимки в results/browser/. |
| 18. Полный ряд и импорт | Через HTTP сверены все 10 958 календарных дат температуры АМЕ-60 за 1992–2021, 8 337 рассчитанных средних и 2 621 пропуск. Исходный CSV Кр1 за 2024, новые данные за 2026 и корректный отказ при ошибках импорта проверены отдельным HTTP-тестом. |
| 19. Материалы команды | Общий файл Figma закреплён в 00_Распределение.md и ПРАВКИ.md. Новые фреймы и замечания можно добавлять в ходе технической проверки. |
| 20. Проверки будущих макетов | Для вкладок обеих страниц явно задан тот же цвет фона, что у шапки. Статический детектор теперь верно распознаёт цвета. Файловые исключения контраста сняты, проверка без конфигурации вернула 0 замечаний. |
| 21. Метеорологические результаты | В results/research/ сохранены три вывода и исходные численные таблицы для защиты. По 8 498 общим парам даты и часа Кр1 холоднее Кр2 в 17 из 24 часовых средних. Наклон температуры АМЕ-60 равен +0,057 °C/год по всем пригодным месяцам и +0,089 при отборе восьми полных лет. |
| 22. Файл Figma | Ссылка на общую страницу сохранена. Подключённый аккаунт Figma получил отказ в доступе к метаданным. Наличие или готовность макетов не проверены. Аналитика, тестирование и локальная сборка выполняются независимо. |
| 23. Ссылки и итоговая приёмка | Ссылка сохраняет станцию, показатель, диапазоны и шаг. Перезагрузка воспроизводит выбранный расчёт. Для почасового сравнения есть отдельная ссылка. По 13 браузерных сценариев прошли на ширинах 390 и 1280 px. Новая сборка комплектуется численными результатами исследования, графиком и сценарием показа. |
| 24. Подготовка к сдаче | Проверены форма, расписание чекпоинтов и видимость GitHub. Репозиторий закрыт. Для экспертов подготовлен способ передачи исходников и результатов через ZIP. В docs/СДАЧА.md есть текст комментария и инструкция по личному входу в облако. |
| 25. Выгрузка за пять суток | В results/examples/kr1-pressure-2024-04-01-to-05.csv сохранены все пять строк давления Кр1. 1 апреля прошли 19 часов, 2–5 апреля пригодных часов нет. Пустые средние сопровождаются числом флагов и объяснением. |
| 26. Чекпоинты и защита | В официальном канале уточнили аудиторию метеокейса B204 и ожидания двух чекпоинтов. Добавлены план разговора, вопрос специалисту о приборе и презентация с доказательствами по пяти критериям. |
| 27. Переходы через ноль | Веб-выборка и CSV позволяют проверить 719 смен знака среднесуточной температуры. Независимый пересчёт исходных файлов воспроизвёл все события. В апреле 2024 обе точки перешли в минус 4 апреля. Кр1 вернулась в плюс 5 апреля, Кр2 — 6-го. |
| 28. Региональный прогноз | В Chromium получен трёхдневный ответ Open-Meteo. Недоступный, устаревший и неполный ответы переключают экран на копию с явной датой. Прогноз не участвует в архивных расчётах. |
| 29. Последние пять суток | Из таблицы выгружаются пять календарных дней до последней записи станции включительно. У АМЕ-60 это 2–6 ноября 2021, у обеих станций Сокол М1 — 27–31 декабря 2025. Это проверено вместе с 13 браузерными сценариями на каждой из двух ширин экрана. |
| 30. Контраст | В 20 состояниях Chromium на ширинах 390 и 1280 px минимальный контраст активного текста составил 5,20:1; у двух вкладок — 11,75:1 и 8,67:1. Статический скан текущих файлов без исключений вернул ноль замечаний. Подробности в results/browser/contrast.json. |
| 31. Календарь температуры | Добавлены три станции и ползунок года. В браузере проверены 365 из 365 пригодных суток Кр1 в 2025 году, 361 из 365 на Кр2, нулевая температура и пустой високосный 2000 год АМЕ-60. Клик по дню ведёт к исходным срокам. Замеры записаны в results/browser/calendar.json. |
| 32. Передача комплекта | В ZIP включены PDF защиты и готовая SQLite с хешем. Сборщик проверяет работу с комплектной базой, затем удаляет её во временной копии и повторяет сборку из данных организаторов. Архив и файл проверки предназначены для передачи через форму сдачи. |
