# Журнал работы

**22 ноября 2026.** Аналитическое ядро и первичная проверка доступны локально. Сайт находится у двух участников. Для начала работы откройте 00_Распределение.md, для данных — results/examples/. Пожелания команды собираются в ПРАВКИ.md.

| Этап | Результат и проверка |
|---|---|
| 1. Постановка | Проект начат в пустой папке. Прочитаны кейс 02, рубрика и паспорт архива. Вложенный промпт используем как метод независимой проверки. |
| 2. Разделение задач | Зоны ответственности и критерии приёмки записаны в 00_Распределение.md. |
| 3. Сценарий | Специалист выбирает станцию и период, находит исключённый месяц и по исходным срокам устанавливает причину. Основной пример — апрель 2024, давление Кр1. |
| 4. Уточнение команды | Сайт передан участникам с Plus и Gemini. Plus владеет JavaScript, Gemini — HTML/CSS и проверкой экранов. Переданы черновики HTML/CSS и частично написанный JavaScript. График, детализация и обработчики остаются участнику Plus. Импорт нового файла снят с обязательств участников. |
| 5. Сборка и контроль | Получены results/weather.sqlite, build.json, station_coverage.csv и parameter_coverage.csv. Совпали 420/420 строк покрытия организатора. За 2024 у Кр1 валидны 363 суток станции и 334 суток давления. У давления за апрель валидны 2/30 суток и подряд неполны 28 суток. |
| 6. Независимая сверка | Проверены исходные 874 560 строк из 35 файлов. Полная сверка с SQLite без расхождений. Подробности в results/audit/ОТЧЁТ.md и CSV рядом. |
| 7. Проверка производных показателей | В results/analysis-checks.json сохранена проверка тренда, отклонений и сравнения температур Кр1/Кр2 по 361 общему дню и 8 498 общим парам «дата и час». Исправлена нормализация направления севера с 360° до 0° на круговом среднем. |
| 8. Передача сайта | Сохранены docs/API.md и реальные ответы в results/examples/. Там доступны год, апрель по суткам, исходные измерения, CSV, сравнение точек и результаты HTTP-проверок. |
| 9. Границы контроля качества | У давления Кр1 1 апреля 2024 все 38 пригодных значений одинаковы при достаточном покрытии. Добавлен сигнал для проверки с сохранением исходного решения. У соседней Кр2 в те же сутки 39 различных значений из 48. |
| 10. Подготовка показа | Добавлены воспроизводимый график покрытия апреля, проверяемый JSON дня, инструктаж по методике и предварительная самооценка. Следующий шаг сайта — связать график, таблицу и исходные сроки. |
| 11. Анализ нового файла | Чтобы двум участникам оставить только веб-задачи, основной блок получил автономный импорт одного CSV/JSON. На файле Кр1 за 2024 совпали все 2 196 суточных, 72 месячных строки по параметрам и 12 станционных месяцев. Добавлены реальный входной JSON на 48 строк и готовый демонстрационный отчёт. |
| 12. Инвентаризация | Для всех 20 сочетаний станции и показателя сохранены число пригодных суток, месяцев и лет в results/series-inventory.csv. |
| 13. Передача участникам | Собран локальный архив handoff/meteo-team.zip с исходными данными, кодом, черновиком сайта и настоящими ответами API. Проверен запуск из отдельной папки на Python 3.9.6 с автоматической сборкой базы и пересчётом суточного JSON. |
