# Метеоархив урочища «Красное»

Приложение для кейса 02 Центрально-Лесного заповедника. На вкладке «Наблюдения» специалист выбирает станции на карте и сравнивает измерения за один или несколько интервалов. Сервер читает архив 1992–2025 годов и подтверждённые загрузки. Архив, схема выбора станций, шрифты и расчёты работают без интернета. Обращения за свежим прогнозом и внешними оценками требуют связи.

**Сайт с PostgreSQL.** При запущенном Docker выполните `python3 setup_compose.py --up` и откройте [Наблюдения на порту 8766](http://127.0.0.1:8766/). Станции, исходники, правки и опубликованные наблюдения сохраняются в постоянном томе PostgreSQL. [Устройство стека, перенос данных и резервные копии](docs/СТЕК.md).

**Автономный показ с SQLite.** Выполните `python3 server.py` и откройте [Наблюдения на порту 8765](http://127.0.0.1:8765/). [Сценарий живой защиты](docs/ПОКАЗ.md).

1. Нажмите **«Выбрать станции»**. Отметьте Кр1 и Кр2 в списке или протяните рамку вокруг маркеров на карте и нажмите «Применить». Ctrl или ⌘ добавляет станции к выделению. Для сдвига карты выберите «Перемещение». Групповой маркер выделяет все станции с общей привязкой.
2. Для новой станции откройте тот же каталог на карте и создайте паспорт. Укажите название, широту, долготу и измеряемые показатели. Для трёх архивных станций общий ориентир — место сбора «Красное» (56.464310, 32.970290) от 26 июля 2019 года. Точные координаты датчиков в исходных материалах отсутствуют. Станция без координат доступна в списке. Диапазон дат общий для всех станций.
3. Откройте **«Файлы и импорт»**, загрузите CSV, XLSX или JSON и выберите станцию. Для неизвестной станции выберите «Новая метеостанция», укажите название, широту и долготу. «Отфильтровать» показывает результат. «Добавить в базу» публикует его на графиках. При повторной обработке используется сохранённый оригинал. В автономном режиме пользовательская база находится в `.local/observations.sqlite3`. Путь можно задать через `METEO_OBSERVATION_DB`.

Обработать уже имеющиеся наблюдения можно в разделе [«Файлы и импорт»](http://127.0.0.1:8766/files). Выберите станцию, показатель и даты. Для внешних оценок программа использует расположение этой станции.

Для сравнения двух сезонов укажите первый период, добавьте второй с помощью «Добавить интервал» и нажмите «Показать». Можно выбрать до 12 интервалов. Соседние интервалы остаются раздельными. Одни и те же сутки нельзя включить в два интервала. Ряды, статистика и покрытие учитывают отмеченные сутки. На шкале выберите редактируемый интервал и масштаб вплоть до недели. Протяните между датами либо передвиньте выбранную границу стрелкой клавиатуры на сутки. Ссылка в адресной строке сохраняет выбранные границы.

Введите даты 01.01.2025–31.12.2025 и выберите «По месяцам». Через «Добавить график» откройте температуру, влажность и давление в любом порядке. На экране карточки одного показателя стоят рядом. В разделе температуры воздуха также находятся разность Кр2 − Кр1 и средний суточный ход.

В «Наблюдениях» сразу доступна офлайн-схема с выбором станций. Зажмите левую кнопку и протяните рамку, чтобы выбрать область. Ctrl или ⌘ добавляют станции к выбору. Кнопки «Вся Россия» и «К станциям» переключают обзор. На карте станции с одним ориентиром объединяются в общую метку. Подложка и географические данные поставляются вместе с сайтом.

В каталоге «+» доступны числовые карточки и матрица покрытия. В ячейках по месяцам показаны пригодные и выбранные календарные сутки. Например, у Кр1 в апреле 2024 года в строке станции 28/30, в строке давления 2/30. По умолчанию матрица скрыта. В редакторе файла можно скачать CSV черновика, исправить значения и приложить его к той же версии. Публикация требует отдельного подтверждения.

[Состав и детализация карты России](docs/КАРТА.md).

**«Скачать график»** на карточке сохраняет её изображение. **«Скачать все графики»** рядом с каталогом собирает все открытые карточки в один ZIP. Выберите SVG, PNG или JPEG. В архив также входит общий многостраничный PDF со всеми выбранными графиками. Файлы пронумерованы по порядку на экране и сохраняют текущий масштаб и видимые ряды. Карточки без данных входят в архив с пояснением причины. Отдельная кнопка таблицы выгружает CSV. [Пример PDF из архива графиков](results/observations/Графики-наблюдений.pdf).

[Материалы для сдачи и расписание чекпоинтов](docs/СДАЧА.md) · [пример CSV за пять суток, 1–5 апреля 2024](results/examples/kr1-pressure-2024-04-01-to-05.csv).

[Презентация для защиты, PDF](docs/Защита-exeCUtor.pdf) · [сценарий первого чекпоинта, B204](docs/СДАЧА.md#что-показать-в-b204).

В [выборке переходов через 0 °C](http://127.0.0.1:8765/events) можно выбрать станцию и даты, перейти к исходным суткам или скачать события в CSV. Для полного архива получено 719 смен знака среднесуточной температуры. На главной странице блок «Таблица последних пяти суток» показывает последние измерения выбранной станции и выгружает их в CSV. [Числа, границы метода и независимый пересчёт](results/research/ПЕРЕХОДЫ-ЧЕРЕЗ-НОЛЬ.md).

## Отфильтровать наблюдения и пересмотреть решения в Excel

В разделе [«Файлы и импорт»](http://127.0.0.1:8766/files) выберите станцию, показатель и даты. Подойдёт архив организаторов или свой файл XLSX, CSV, JSON. Базовый режим проверяет диапазон и приборные флаги. Границы допустимых значений и пороги дополнительных фильтров можно вводить вручную. Отдельно включаются записи с одинаковым временем, выброс среди соседних значений, скачок с возвратом и долгое повторение одного показания. Для каждого срока, дня и месяца видны рабочее решение и решение по кейсу. [Методика с примерами](docs/ФИЛЬТРАЦИЯ.md).

В рабочем Excel видны исходные сроки, решения фильтров, модельная оценка, внешняя сверка и итог. Копия исходного XLSX сохраняет отметки на листе станции. На листе «Управление» можно переключить решение для всех строк, на листе «Сроки» — вернуть или исключить отдельное измерение. [Пример книги](results/review/review-example.xlsx).

Восстановление относится только к прошлым измерениям. Модель использует пригодные соседние сроки той же станции. При внешней сверке запросы привязаны к координатам станции и времени пропуска. Поправка ограничена и допускается только после проверки на предыдущих данных. При нехватке соседних измерений пропуск остаётся. [Проверка на скрытых измерениях](results/review/ПРОВЕРКА-ВОССТАНОВЛЕНИЯ.md).

Архивные расчёты используют только наблюдения станций. При отсутствии связи экран показывает подписанную копию и дату получения. ## Результаты на архиве

- **Кр1, апрель 2024.** Из-за недостаточного покрытия давления прошли 2 из 30 суток. На Кр2 прошли все 30, среднее давление составило 980,16 гПа.
- **Поляна и поле, 2025.** На 361 общей дате Кр1 холоднее Кр2 в 8 из 12 месячных средних. Наибольшие часовые разности Кр1 − Кр2 составили +0,857 °C в 13:00 и −0,742 °C в 20:00 по исходному времени.
- **АМЕ-60, 1992–2021.** Наклон температуры равен +0,057 °C/год по 254 пригодным месяцам и +0,089 °C/год по 96 месяцам восьми полных лет. Оценка чувствительна к тому, какие годы попали в выборку.

## Запуск

Для автономного режима потребуется Python 3.9 или новее. Расчёты и локальный HTTP-сервер работают на стандартной библиотеке. Контейнер поставляет Python, Waitress и драйвер PostgreSQL. Запускайте команды из корня проекта.

```sh
python3 journal.py
python3 server.py
```

Первая команда сразу выводит годовую таблицу давления Кр1 с помесячным разбором и причинами пропусков. В репозитории и ZIP лежит готовая база. Сервер проверяет SHA-256 архива и базы при запуске. Если базы нет или контрольные суммы изменились, он пересобирает её из включённого ZIP. Вторую команду оставьте запущенной для работы сайта. Откройте [список маршрутов](http://127.0.0.1:8765/api) или [расчёт давления за 2024 год](http://127.0.0.1:8765/api/series?station=kr1&param=pressure_hpa&start=2024-01-01&end=2024-12-31&grain=month). Рабочий интерфейс доступен на [главной странице](http://127.0.0.1:8765/). Другой порт задаётся через `--port 8766`.

Регистрация станции, импорт, обработка и публикация доступны из одного интерфейса без входа. Оба варианта запуска по умолчанию публикуют сайт только на этом компьютере.

## Отдельный отчёт по одному файлу

В [разделе «Файлы и импорт»](http://127.0.0.1:8766/files?source=upload) выберите станцию Кр1 и загрузите [файл за 1 апреля 2024 года](results/examples/kr1-station-2024-04-01.json). Откройте файл в очереди, укажите давление и нажмите «Отфильтровать». В исходнике 48 строк. После проверки остаются 38 пригодных значений за 19 разных часов, среднее за сутки составляет 1005,45 гПа. В рабочем Excel видны исходные значения и причины исключений.

Для отдельного годового отчёта запустите команду

```sh
python3 import_station.py --station kr1 --year 2024 --input results/examples/kr1-station-2024-04-01.json --output-dir my-import
```

В примере — 48 реальных исходных строк за 1 апреля. Вместо него можно выбрать годовой CSV станции с колонками организатора или JSON-массив таких же записей. Один запуск обрабатывает один календарный год, допускаются годы вне демонстрационного архива. В отдельной папке появляются `daily.csv`, `monthly.csv`, `station_coverage.csv` и манифест с хешами. По одному дню можно получить суточный результат, апрель при этом не проходит месячное покрытие. [Готовый отчёт из примера](results/import-example/) и [проверка импорта целого года](results/import-check.json).

Этот инструмент создаёт отдельный отчёт. Для публикации наблюдений на общих графиках используйте страницу «Файлы и импорт». Маршрут `/api/raw` сохраняет доступ к исходным записям организаторов для независимой проверки через `replay_day.py`.


## Браузерная приёмка и передача команде

Две ширины экрана и полный путь до источника проверяет `node checks/browser.cjs` при работающем сервере. Для этого теста нужны Node.js, пакет Playwright и Chromium. Их можно установить отдельно через `npm install --no-save playwright` и `npx playwright install chromium`. Основной продукт работает на Python без этих зависимостей. При нестандартном пути браузера тест принимает переменную `METEO_CHROMIUM`. Порт тестируемого сервера можно передать через `METEO_TEST_PORT`.

Для главной страницы запустите `node checks/observations.cjs`. Для проверки очереди, реальных CSV, XLSX и JSON и исходника в Excel выполните `node checks/files.cjs`. Второй сценарий поднимает собственный сервер с временной базой. Проверка `python3 -m unittest discover -s checks` охватывает расчёты и HTTP. Для независимой сверки внешних оценок выполните `python3 -m unittest checks.check_external_fill`.

[Наблюдения](results/browser/observations.png) · [Карта станций](results/browser/observations-stations.png) · [Сравнение станций](results/browser/observations-comparison.png) · [Предпросмотр фильтрации](results/browser/files-preview-1280.png) · [Протокол импорта и восстановления данных](results/observations/workflow.json).

Команда `python3 pack_team.py` собирает `handoff/meteo-team.zip`, распаковывает его во временную папку и проверяет запуск с готовой базой, её сборку с нуля в отдельной копии, месячную таблицу, сверку исходного дня и импорт файла. SHA-256 передаваемой версии записывается рядом в `Проверка.txt`.
