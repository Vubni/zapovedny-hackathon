# Метеоархив урочища «Красное»

Приложение для кейса 02 Центрально-Лесного заповедника. На вкладке «Наблюдения» специалист выбирает станции на карте и сравнивает измерения за общий период. Сервер читает архив 1992–2025 годов и подтверждённые загрузки. Архив, карта станций, шрифты и расчёты работают без интернета. Обращения за свежим прогнозом и внешними оценками требуют связи.

**Начать показ** — выполните `python3 server.py` и откройте [Наблюдения](http://127.0.0.1:8765/). [Сценарий живой защиты](docs/ПОКАЗ.md).

1. Нажмите **«Выбрать станции»**, отметьте Кр1 и Кр2 и примените выбор. Введите даты 01.01.2025–31.12.2025, выберите «По месяцам». Кнопка «Добавить график» открывает каталог, включая разницу Кр2 − Кр1 и средний суточный ход. В карточке можно проверить покрытие каждого ряда и скачать таблицу или иллюстрацию.
2. Для новой станции откройте тот же каталог на карте и создайте паспорт. Укажите профиль прибора и, если известны, координаты. У трёх архивных станций показан общий ориентир урочища. Станция без координат доступна в списке. Диапазон дат общий для всех станций.
3. Откройте **«Файлы и импорт»**, загрузите CSV или XLSX и выберите станцию. «Отфильтровать» показывает результат. «Добавить в базу» публикует его на графиках. При повторной обработке используется сохранённый оригинал. Оригиналы, паспорта и подтверждённые версии хранятся на этом компьютере в `.local/observations.sqlite3`. Путь можно задать через `METEO_OBSERVATION_DB`. Для переноса пользовательских данных скопируйте эту базу при остановленном сервере.

Углублённая проверка отдельного архивного дня, исходные строки, экспорт последних пяти суток и сравнение с официальной методикой доступны в [журнале наблюдений](http://127.0.0.1:8765/journal).

[Материалы для сдачи и расписание чекпоинтов](docs/СДАЧА.md) · [пример CSV за пять суток, 1–5 апреля 2024](results/examples/kr1-pressure-2024-04-01-to-05.csv).

[Презентация для защиты, PDF](docs/Защита-exeCUtor.pdf) · [сценарий первого чекпоинта, B204](docs/СДАЧА.md#что-показать-в-b204).

[Скачать готовый ZIP для передачи жюри](handoff/meteo-team.zip) · [контрольная сумма и проверка распаковки](handoff/Проверка.txt).

В [выборке переходов через 0 °C](http://127.0.0.1:8765/events) можно выбрать станцию и даты, перейти к исходным суткам или скачать события в CSV. Для полного архива получено 719 смен знака среднесуточной температуры. Отдельная ссылка в таблице метеожурнала выгружает последние пять календарных суток архива станции для выбранного показателя. [Числа, границы метода и независимый пересчёт](results/research/ПЕРЕХОДЫ-ЧЕРЕЗ-НОЛЬ.md).

[Календарь температуры](http://127.0.0.1:8765/calendar) показывает год по дням. Сдвиньте ползунок года или смените станцию, чтобы сравнить сезонный ход по одной шкале. В апреле 2024 у Кр1 приняты 28 из 30 суток. Выберите день, чтобы проверить значение и покрытие.

## Отфильтровать наблюдения и пересмотреть решения в Excel

В разделе [«Фильтрация и Excel»](http://127.0.0.1:8765/review) выберите станцию, показатель и даты. Подойдёт архив организаторов или свой файл XLSX, CSV, JSON. Базовый режим проверяет диапазон и приборные флаги. Конфликты, Хэмпель, скачок с возвратом, залипание датчика и сверку температур поляны и поля можно включать отдельно. Для каждого срока, дня и месяца видны рабочее решение и решение по кейсу. [Методика с примерами](docs/ФИЛЬТРАЦИЯ.md).

Выгрузка содержит все строки выбранного интервала. У исходного XLSX можно скачать копию с отметками прямо на листе станции. На листе «Управление» ячейка B5 переключает режим сразу для всех строк. На листе «Сроки» можно отдельно вернуть измерение, исключить его или выбрать внешнюю оценку. [Пример книги за апрель](results/review/review-example.xlsx).

## Прогноз для района заповедника

В [разделе «Прогноз на 3 дня»](http://127.0.0.1:8765/forecast) показаны суточные минимум и максимум температуры, сумма осадков и максимальная скорость ветра. При открытии страницы браузер запрашивает Open-Meteo для точки 56,52° с. ш., 32,87° в. д., выбранной внутри границ заповедника. Это региональный прогноз модели. Архивные расчёты используют только наблюдения станций. При отсутствии связи экран показывает подписанную копию и дату получения. [Сохранённый ответ API](web/forecast-example.json) · [браузерная проверка](results/browser/forecast.json) · [границы заповедника](https://www.clgz.ru/node/19196?language=ru) · [документация Open-Meteo](https://open-meteo.com/en/docs).

[Карта осадков](http://127.0.0.1:8765/precip) показывает почасовую сумму в 25 точках вокруг заповедника. Время переключается ползунком. [Модель станции](http://127.0.0.1:8765/model) прогнозирует следующую среднесуточную температуру по двум последовательным суткам наблюдений. Рядом приведена ошибка на последнем году, отделённом от обучения. [Коэффициенты и проверка точности](results/model/МЕТОДИКА.md).

## Результаты на архиве

- **Кр1, апрель 2024.** Из-за недостаточного покрытия давления прошли 2 из 30 суток. На Кр2 прошли все 30, среднее давление составило 980,16 гПа.
- **Поляна и поле, 2025.** На 361 общей дате Кр1 холоднее Кр2 в 8 из 12 месячных средних. Наибольшие часовые разности Кр1 − Кр2 составили +0,857 °C в 13:00 и −0,742 °C в 20:00 по исходному времени.
- **АМЕ-60, 1992–2021.** Наклон температуры равен +0,057 °C/год по 254 пригодным месяцам и +0,089 °C/год по 96 месяцам восьми полных лет. Оценка чувствительна к тому, какие годы попали в выборку.

## Запуск

Потребуется Python 3.9 или новее. Для расчётов, API и проверок используются модули стандартной библиотеки. Запускайте команды из корня проекта.

```sh
python3 journal.py
python3 server.py
```

Первая команда сразу выводит годовую таблицу давления Кр1 с помесячным разбором и причинами пропусков. В репозитории и ZIP лежит готовая база. Сервер проверяет SHA-256 архива и базы при запуске. Если базы нет или контрольные суммы изменились, он пересобирает её из включённого ZIP. Вторую команду оставьте запущенной для работы сайта. Откройте [список маршрутов](http://127.0.0.1:8765/api) или [расчёт давления за 2024 год](http://127.0.0.1:8765/api/series?station=kr1&param=pressure_hpa&start=2024-01-01&end=2024-12-31&grain=month). Рабочий интерфейс доступен на [главной странице](http://127.0.0.1:8765/). Другой порт задаётся через `--port 8766`.

## Отдельный отчёт по одному файлу

В браузере откройте [импорт наблюдений](http://127.0.0.1:8765/import). Выберите файл, станцию, год и показатель. Кнопка «Открыть пример Кр1» воспроизводит реальный случай без подготовки файла. Для пакетной обработки тот же расчёт доступен в командной строке.

```sh
python3 import_station.py --station kr1 --year 2024 --input results/examples/kr1-station-2024-04-01.json --output-dir my-import
```

В примере — 48 реальных исходных строк за 1 апреля. Вместо него можно выбрать годовой CSV станции с колонками организатора или JSON-массив таких же записей. Один запуск обрабатывает один календарный год, допускаются годы вне демонстрационного архива. В отдельной папке появляются `daily.csv`, `monthly.csv`, `station_coverage.csv` и манифест с хешами. По одному дню можно получить суточный результат, апрель при этом не проходит месячное покрытие. [Готовый отчёт из примера](results/import-example/) и [проверка импорта целого года](results/import-check.json).

Этот инструмент создаёт отдельный отчёт. Для публикации наблюдений на общих графиках используйте страницу «Файлы и импорт». Маршрут `/api/raw` сохраняет доступ к исходным записям организаторов для независимой проверки через `replay_day.py`.


## Браузерная приёмка и передача команде

Две ширины экрана и полный путь до источника проверяет `node checks/browser.cjs` при работающем сервере. Для этого теста нужны Node.js, пакет Playwright и Chromium. Их можно установить отдельно через `npm install --no-save playwright` и `npx playwright install chromium`. Основной продукт работает на Python без этих зависимостей. При нестандартном пути браузера тест принимает переменную `METEO_CHROMIUM`. Порт тестируемого сервера можно передать через `METEO_TEST_PORT`.

Для главной страницы запустите `node checks/observations.cjs`. Для проверки очереди, реальных CSV/XLSX и исходника в Excel выполните `node checks/files.cjs`. Второй сценарий поднимает собственный сервер с временной базой. Проверка `python3 -m unittest discover -s checks` охватывает расчёты и HTTP. Для независимой сверки внешних оценок выполните `python3 -m unittest checks.check_external_fill`.
