# Сдача решения exeCUtor

В форме выберите **«Анализ метеоданных»** и укажите название команды **exeCUtor**, как при регистрации. Форму можно дополнять следующими отправками с тем же названием. [Форма организаторов](https://yc-hack.ru/submit)

## Что приложить

1. Приложите `handoff/meteo-team.zip`. В нём исходный архив организаторов, код, проверенные результаты и инструкция. Собрать и проверить ZIP из этого репозитория можно командой `python3 pack_team.py`.
2. В поле ссылок укажите `https://github.com/Vubni/zapovedny-hackathon`. На 22 ноября репозиторий закрытый. ZIP позволит экспертам работать с полной версией проекта. Для просмотра непосредственно на GitHub им понадобится доступ.
3. Короткий комментарий для экспертов приведён ниже. Презентацию удобно также приложить отдельным файлом, чтобы её можно было открыть до распаковки.

> После распаковки запустите `python3 server.py` из корня проекта и откройте http://127.0.0.1:8765/. Требуется Python 3.9 или новее. База соберётся из включённого архива при первом запуске. Для проверки выберите давление Кр1 за апрель 2024 года и откройте 29 апреля. В этот день 31 пригодное измерение охватывает 15 разных часов при пороге 18. Результаты исследования и исходные численные таблицы находятся в results/research/, сценарий показа — в docs/ПОКАЗ.md.

## Доступ к Yandex Cloud

Каждый участник получает личный аккаунт. На странице ресурсов он указывает своё ФИО и номер команды, выданный организаторами. Затем входит с полным логином, меняет начальный пароль в профиле при первом входе и переходит по ссылке «Открыть каталог команды». Если пароль уже меняли, нужен выбранный участником пароль. Архивную аналитику и показ метеожурнала можно запустить локально. [Инструкция организаторов](https://yc-hack.ru/#access)
