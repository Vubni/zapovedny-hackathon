# Сценарий живой защиты

Откройте [Наблюдения](http://127.0.0.1:8765/), нажмите «Выбрать станции» и отметьте Кр1 и Кр2. Выберите весь 2025 год и группировку по месяцам. В карточке температуры видны две линии. Через «Добавить график» откройте разницу температур и средний суточный ход. В январе в поле теплее, чем на поляне, примерно на 0,19 °C по общим пригодным суткам. Легенда и CSV сохраняют порядок вычитания Кр2 − Кр1.

Для демонстрации длинного архива введите 01.01.2005–31.12.2015. Оставьте только Кр1, затем выберите АМЕ-60. В первом случае карточка объясняет отсутствие измерений, во втором появляются наблюдения АМЕ-60 с разрывами. В обоих случаях даты остаются прежними.

В разделе «Файлы и импорт» откройте пример Кр1 или загрузите файл на свою станцию. Нажмите «Отфильтровать», выберите параметр в предпросмотре и скачайте рабочую книгу. Для демонстрации подтверждения, повторного расчёта и удаления используйте отдельную рабочую базу. После удаления очищенной версии её исходник остаётся в истории.

**Можно ли включить давление с поляны в апрельскую сводку 2024 года?** Для разбора вплоть до записей прибора откройте [журнал](http://127.0.0.1:8765/journal). Все числа ниже можно получить из приложенного архива.

```sh
python3 replay_day.py results/examples/kr1-pressure-april-29-incomplete.json --archive data/meteo_hack_dataset.zip
```

В команде можно заменить готовый пример на JSON, только что скачанный из окна исходных сроков.

**Если спросят, можно ли доверять прошедшему дню.** На Кр1 1 апреля все 38 пригодных значений равны 1005,45 гПа. День проходит правило покрытия. Интерфейс показывает замечание для ручной проверки. На Кр2 в тот же день 39 различных значений из 48. Причину повторов сможет установить специалист с дополнительными сведениями о приборе.

**Если спросят про длинный ряд.** Выберите АМЕ-60, температуру воздуха, период 07.02.1993–20.09.2020 и шаг «месяц». Наклон около +0,063 °C/год по 238 целым пригодным месяцам. Для сравнения отклонений выбираются годы в блоке базы. Объясните, что пропуски меняют состав использованных лет. У разных приборов и точек отдельные ряды.

**Если спросят про микроклимат.** В разделе «Поляна и поле» выберите месяцы и затем суточный ход. В 2025 году сравнение использует 361 общую дату и 8 498 общих пар «дата и час». В январе на поляне среднее около −1,10 °C, в поле −0,92 °C, разность около −0,19 °C. Это сравнение наблюдений указанных точек за выбранный год.

Для разбора вопросов по температуре откройте [полный отчёт с числом дней и пар часов](../results/research/ВЫВОДЫ.md). Там отдельно показана чувствительность наклона к отбору полных лет.

## Ссылки для повторения

Для демонстрации решения по спорному датчику откройте [фильтрацию](http://127.0.0.1:8765/review), выберите давление Кр1 за 1 апреля 2024 и нажмите «Отфильтровать». По базовым правилам приняты 38 одинаковых измерений. Включите залипание и повторите расчёт. В рабочей копии все 38 отклонены, а официальное решение рядом позволяет увидеть эффект именно этого фильтра. В Excel переключите B5 на «Вернуть все исходные»; число принятых в рабочем наборе изменится.

Для разбора пропуска возьмите температуру Кр1 за 21 апреля 2024, включите внешнюю оценку и выберите московское время как допущение. Откройте созданный срок 11:00. Два источника дали 9,8 и 8,2 °C за одинаковый час, рабочая оценка 9,00 °C. Для прогноза следующих суток перейдите к [модели станции](http://127.0.0.1:8765/model), для прогноза осадков — к [почасовой карте](http://127.0.0.1:8765/precip).

При работающем сервере можно открыть тот же расчёт на другом запуске. После успешной смены фильтров строка адреса сохраняет выбор.
