# Сценарий живой защиты

## Публичный архив

Откройте [Наблюдения](http://127.0.0.1:8766/), нажмите «Выбрать станции» и отметьте Кр1 и Кр2. Выберите весь 2025 год и группировку по месяцам. В карточке температуры видны две линии. Через «Добавить график» откройте разницу температур и средний суточный ход. В январе в поле теплее, чем на поляне, примерно на 0,19 °C по общим пригодным суткам. Легенда и CSV сохраняют порядок вычитания Кр2 − Кр1.

Карта открывает доступные станции текущего пространства. Нажмите на маркер, чтобы посмотреть паспорт и выбрать станцию. Для Кр1 и Кр2 районная точка карты относится к урочищу «Красное». Добавьте второй интервал или включите покрытие. Серии посчитаны по отмеченным интервалам, а в матрице покрытия учитываются только выбранные сутки.

Для демонстрации длинного архива введите 01.01.2005–31.12.2015. Оставьте только Кр1, затем выберите АМЕ-60. В первом случае карточка объясняет отсутствие измерений, во втором появляются наблюдения АМЕ-60 с разрывами. В обоих случаях даты остаются прежними.

**Можно ли включить давление с поляны в апрельскую сводку 2024 года?** В «Наблюдениях» выберите Кр1 и добавьте карточку покрытия. Исходные сроки открываются в публичном журнале `/journal`. Все числа ниже можно получить из приложенного архива.

| Действие на экране | Что увидит жюри | Что это доказывает |

```sh
python3 replay_day.py results/examples/kr1-pressure-april-29-incomplete.json --archive data/meteo_hack_dataset.zip
```

В команде можно заменить готовый пример на JSON, только что скачанный из окна исходных сроков.

**Если спросят, можно ли доверять прошедшему дню.** На Кр1 1 апреля все 38 пригодных значений равны 1005,45 гПа. День проходит правило покрытия. Интерфейс показывает замечание для ручной проверки. На Кр2 в тот же день 39 различных значений из 48. Причину повторов сможет установить специалист с дополнительными сведениями о приборе.

**Если спросят про длинный ряд.** Выберите АМЕ-60, температуру воздуха, период 07.02.1993–20.09.2020 и шаг «месяц». Наклон около +0,063 °C/год по 238 целым пригодным месяцам. Для сравнения отклонений выбираются годы в блоке базы. Объясните, что пропуски меняют состав использованных лет. У разных приборов и точек отдельные ряды.

**Если спросят про микроклимат.** В разделе «Поляна и поле» выберите месяцы и затем суточный ход. В 2025 году сравнение использует 361 общую дату и 8 498 общих пар «дата и час». В январе на поляне среднее около −1,10 °C, в поле −0,92 °C, разность около −0,19 °C. Это сравнение наблюдений указанных точек за выбранный год.

Для разбора вопросов по температуре откройте [полный отчёт с числом дней и пар часов](../results/research/ВЫВОДЫ.md). Там отдельно показана чувствительность наклона к отбору полных лет.

## Кабинет и данные центра

Откройте `/import` в гостевом окне. Прежний адрес ведёт в «Файлы и импорт», где гостю предлагают войти через `/account`. Публичные наблюдения доступны из этого окна только по исходному архиву. Закрытый запрос гостя к `/api/files` возвращает HTTP 401.

Для работы с файлами войдите через «Мой аккаунт». Глобальный администратор может сменить центр в разделе «Управление центрами». Покажите, что новый центр открывается с пустым каталогом станций и файлов. Вернитесь в Центрально-Лесной заповедник для примеров Кр1. Исследователь может создать черновик из наблюдений, применить фильтры и скачать рабочую книгу. Администратор может также загрузить исходный файл, подтвердить обработку или снять публикацию. Для показа изменений используйте отдельную рабочую базу. При снятии публикации исходник остаётся в истории.

Войдите как администратор Центрально-Лесного заповедника, откройте «Файлы и импорт» и загрузите [JSON за 1 апреля](../results/examples/kr1-station-2024-04-01.json) на Кр1. Проверьте давление в предпросмотре и скачайте Excel. В известном примере 48 исходных строк, 38 пригодных значений давления в 19 часах и среднее 1005,45 гПа. Для повторения отдельного расчёта из JSON запустите `python3 check_import_http.py`. Скрипт сам создаёт временную базу и входит под администратором.

Чтобы сохранить фильтры демонстрации, нажмите «Сохранить сессию» рядом с заголовком «Графики» на странице «Наблюдения» и введите название. В кабинете откройте нужную запись из списка «Сохранённые сессии». Восстанавливаются станции, интервалы, графики и настройки показа. В списке видны только личные сессии текущего центра. ## Ссылки для повторения

После входа в Центрально-Лесной заповедник откройте [фильтрацию](http://127.0.0.1:8766/files?source=observations&station=kr1&param=pressure_hpa&start=2024-04-01&end=2024-04-01), выберите давление Кр1 за 1 апреля 2024 и нажмите «Отфильтровать». По базовым правилам приняты 38 одинаковых измерений. Включите залипание и повторите расчёт. В рабочей копии все 38 отклонены, а официальное решение рядом позволяет увидеть эффект именно этого фильтра. В Excel переключите B5 на «Вернуть все исходные», чтобы вернуть значения в рабочем наборе.

В том же центре для разбора пропуска выберите в [обработке](http://127.0.0.1:8766/files) Кр1, температуру воздуха и сутки из апреля 2024. Включите восстановление по данным станции. При внешней сверке поясните выбор времени архива и покажите отдельно модель, внешние источники и конечную рабочую оценку. Для прогноза на следующие три дня откройте [внешний прогноз Open-Meteo](http://127.0.0.1:8766/forecast), затем [почасовую карту осадков](http://127.0.0.1:8766/precip).

При работающем сервере можно открыть тот же расчёт на другом запуске. После успешной смены фильтров строка адреса сохраняет выбор.
