# Доступ к Метеоархиву

Гость может открыть «Наблюдения», карту архивных станций и исходный журнал Центрально-Лесного заповедника. В публичных графиках и таблицах используются только данные из архива организаторов. Пользовательские станции, файлы, черновики и подтверждённые импорты доступны после входа в рабочий центр.

## Права

| Действие | Гость | Исследователь | Администратор центра | Глобальный администратор |
|---|---|---|---|---|
| Наблюдения, карта и покрытие | Публичный исходный архив | Свой центр | Свой центр | Активный центр |
| История файлов, исходники и выгрузки центра | — | Свой центр | Свой центр | Активный центр |
| Черновик из наблюдений, предпросмотр фильтров и отдельная рабочая книга | — | Свой центр | Свой центр | Активный центр |
| Регистрация станций, загрузка файлов и исправлений, подтверждение и снятие публикации | — | — | Свой центр | Активный центр |
| Личные сессии наблюдений | — | Свои в текущем центре | Свои в текущем центре | Свои в активном центре |
| Добавление пользователей | — | — | Исследователи своего центра | Администраторы выбранного центра |
| Создание центров и смена активного центра | — | — | — | Да |

Исходный архив входит в рабочее пространство Центрально-Лесного заповедника. После входа в этот центр «Наблюдения» также учитывают его подтверждённые импорты. Страница `/journal` показывает исходный архив. Другой центр начинает с пустого каталога и видит только свои станции и данные. Ссылка с идентификатором файла или токеном отчёта действует в пределах центра, где создан результат. Личные сессии привязаны также к учётной записи.

## Первый вход

Для Docker Compose из корня репозитория поднимите стек и создайте первого глобального администратора. Замените адрес и имя на свои. Команда запросит пароль и его подтверждение в терминале.

```sh
python3 setup_compose.py --up
docker compose exec web python accounts.py bootstrap --email admin@example.test --name "Администратор архива"
```

После этого откройте `/account` по адресу приложения. Стандартный адрес Compose — `http://127.0.0.1:8766/account`.

Для локального запуска на SQLite используйте один путь к рабочей базе в обеих командах. Выполните следующие команды из корня репозитория.

```sh
unset METEO_DATABASE_URL
export METEO_OBSERVATION_DB="$PWD/.local/observations.sqlite3"
python3 accounts.py bootstrap --email admin@example.test --name "Администратор архива"
python3 server.py --port 8765
```

В этом режиме кабинет находится по адресу `http://127.0.0.1:8765/account`. Bootstrap выполняется один раз для выбранной базы. Пароль вводится в терминале без отображения. В репозиторий и историю команд его не добавляют. Локальный файл наблюдений и соседний каталог баз других центров содержат рабочие данные.

## Смена центра

1. Глобальный администратор открывает «Мой аккаунт», выбирает рабочий центр в разделе «Управление центрами» и нажимает «Сменить центр». В кабинете отображается активный центр текущего входа.
2. Чтобы подключить новый центр, создайте его в этом же разделе. Добавьте для него администратора в карточке «Пригласить администратора центра».
3. Администратор центра входит под своей учётной записью и использует действие «Добавить исследователя». Для обеих ролей центр назначается при создании учётной записи.

## Личные сессии и фильтры

1. В «Наблюдениях» отметьте станции на карте, выберите даты или несколько интервалов, настройте графики, группировку, покрытие и показатели.
2. Нажмите «Сохранить сессию» рядом с заголовком «Графики» и дайте ей название. Если вход ещё не выполнен, откроется кабинет.
3. Чтобы восстановить выбранный вид, откройте «Мой аккаунт» → «Сохранённые сессии» и нажмите «Открыть» у нужного имени. Там же можно удалить сессию. Глобальный администратор сначала выбирает тот центр, в котором создавал сессию.

В сессию входят только настройки страницы, включая интервалы, выбранные графики, скрытые ряды и масштаб там, где он задан. При открытии приложение читает доступные в центре данные на текущий момент. Если передаёте ссылку на наблюдения, получатель увидит данные в пределах своего доступа.
