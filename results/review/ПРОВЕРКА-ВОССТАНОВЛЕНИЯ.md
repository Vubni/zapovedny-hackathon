# Проверка восстановления температуры воздуха

Использованы исходные сроки архива за 2021 год для АМЕ‑60 и за 2025 год для Кр1 и Кр2. Для каждого сочетания станции, регулярного шага и длины пропуска скрыты до 200 непересекающихся блоков реально измеренной температуры. Перед применением модели истинные значения удалены. Есть два прогона с одинаковой выборкой. В первом сохранены сроки с пустой температурой, во втором целевые сроки удалены целиком. Исходные флаги качества и конфликтные сроки сохранены. Все кандидаты имеют пригодные наблюдения внутри блока и по обе стороны от него.

Локальная модель восстанавливает короткий разрыв интерполяцией между двумя пригодными якорями. Поправку к интерполяции она оценивает по более ранним пригодным срокам этой же станции. Проверка сверяет, что оба якоря видимы после маскирования, а поправка обучена до восстанавливаемого срока. Сравнение проведено с линейной интерполяцией без поправки и с переносом последнего известного значения. В таблицах ниже показаны результаты для сохранённых пустых сроков. Удаление сроков дало ту же полноту и те же ошибки.

## Одиночные локально восстановленные сроки

| Станция и год | Шаг | Восстановлено | Локальная модель MAE / RMSE, °C | Линейная MAE / RMSE, °C | Последнее значение MAE / RMSE, °C |
|---|---:|---:|---:|---:|---:|
| АМЕ‑60, 2021 | 15 мин | 200 / 200 | 0,1175 / 0,2332 | 0,1173 / 0,2332 | 0,2770 / 0,4205 |
| Кр1, 2025 | 30 мин | 200 / 200 | 0,2408 / 0,4117 | 0,2426 / 0,4133 | 0,4745 / 0,8965 |
| Кр2, 2025 | 30 мин | 200 / 200 | 0,1572 / 0,2558 | 0,1576 / 0,2561 | 0,3459 / 0,5592 |

Простой перенос последнего значения оказался менее точным на всех трёх станциях. Калибровка линейной интерполяции изменила MAE менее чем на 0,002 °C на каждой станции. У АМЕ‑60 ошибка слегка выросла, у Кр1 и Кр2 слегка снизилась. Польза калибровки зависит от ряда.

## Границы заполнения

| Станция | Шаг измерений | Скрыт 1 срок | Скрыты 2 срока подряд | Скрыты 4 срока подряд |
|---|---:|---:|---:|---:|
| АМЕ‑60 | 15 мин | 200 / 200 | 0 / 400 | 0 / 800 |
| Кр1 | 30 мин | 200 / 200 | 0 / 400 | 0 / 800 |
| Кр1 | 60 мин | 0 / 200 | 0 / 400 | 0 / 800 |
| Кр2 | 30 мин | 200 / 200 | 0 / 400 | 0 / 800 |
| Кр2 | 60 мин | 0 / 200 | 0 / 400 | 0 / 800 |

Интерполятор допускает расстояние до двух преобладающих шагов между якорями. В смешанных рядах Кр1 и Кр2 за 2025 год выбран шаг 30 минут. Поэтому одиночный пропуск внутри часового фрагмента остался пустым. У длинных блоков нет оценки ошибки локальной модели. Ошибки баз на всех искусственно скрытых точках сохранены в JSON.

Выборка характеризует искусственные пропуски между пригодными измерениями температуры. Для последовательностей с отказами прибора, разрывов без измерения с одной стороны и других метеопараметров нужна отдельная проверка. Обе стороны пропуска доступны при ретроспективном восстановлении. Краткосрочный прогноз для района поступает из внешнего прогнозного API.

## Проверка мягкой поправки в Красном

Для Красного запрошены данные ERA5 через Open-Meteo и MERRA‑2 через NASA POWER на координатах 56,46431° с. ш. и 32,97029° в. д. Получены оба ответа HTTP 200 за 31 марта–1 мая 2024 года. Запас по датам нужен для перевода на время источников и обработки крайних часов. Запрошенная точка относится к району наблюдений. Узел ERA5 расположен в 56,5° с. ш. и 33° в. д., точка в ответе NASA POWER — в 56,464° с. ш. и 32,97° в. д. [Запросы, время получения и SHA-256 ответов](external/krasnoe-april-2024-retrieval.json).

Скрыты по 200 одиночных получасовых измерений Кр1 и Кр2 за апрель 2024 года. Локальная модель восстановила все 400. В эксперименте использована заранее зафиксированная схема с двумя источниками, ограничениями 2 °C по расхождению между источниками и 2 °C по отклонению от локальной оценки. Вес ориентира равен 25%, изменение ограничено сверху 0,5 °C и оценкой собственной ошибки модели. Часовой пояс архива не подтверждён заказчиком, поэтому приведены обе гипотезы. Рабочий режим дополнительно разрешает поправку только при подтверждённой пользе на прежних наблюдениях станции. Таблица показывает фиксированную схему до введения этого условия.

| Станция | Часовой пояс | Минутные сроки | Поправлено из 200 | Локальная MAE / RMSE, °C | После поправки MAE / RMSE, °C |
|---|---|---|---:|---:|---:|
| Кр1 | UTC | Пропускать | 0 | 0,2883 / 0,4741 | 0,2883 / 0,4741 |
| Кр1 | МСК | Пропускать | 0 | 0,2883 / 0,4741 | 0,2883 / 0,4741 |
| Кр1 | UTC | Интерполировать | 76 | 0,2883 / 0,4741 | 0,3176 / 0,4960 |
| Кр1 | МСК | Интерполировать | 105 | 0,2883 / 0,4741 | 0,3243 / 0,4991 |
| Кр2 | UTC | Пропускать | 2 | 0,2055 / 0,3046 | 0,2061 / 0,3050 |
| Кр2 | МСК | Пропускать | 2 | 0,2055 / 0,3046 | 0,2067 / 0,3052 |
| Кр2 | UTC | Интерполировать | 78 | 0,2055 / 0,3046 | 0,2303 / 0,3193 |
| Кр2 | МСК | Интерполировать | 108 | 0,2055 / 0,3046 | 0,2248 / 0,3115 |

В этом месяце даже ограниченная внешняя температурная поправка увеличила MAE при обоих предположениях о часовом поясе. Результат относится к двум рядам температуры за один месяц. Он поддерживает использование внешних значений для сверки и сохранение локальной температуры основной оценкой. [Числа по каждому сценарию](gap-fill-krasnoe.json).

Рабочая проверка рассматривает до 96 предшествующих парных ошибок по этой же станции. Для допуска нужно не менее 20 пар, меньшая MAE и RMSE без ухудшения. Пара попадает в проверку только после правого якоря и окончания интервалов всех использованных внешних значений. На апрельской выборке условие отклонило все 371 поправку, которые допускала фиксированная схема в восьми сценариях. У 311 кандидатных поправок уже было достаточно предыдущих пар, но пороги по ошибкам не выполнены. Во всех сценариях итоговая MAE осталась 0,28835 °C на Кр1 и 0,20550 °C на Кр2. Контрольный расчёт по каждому сценарию с внешними значениями повторён с рядом, обрезанным до проверяемого срока. Результат совпал.

```sh
python3 -m checks.gap_fill_archive
python3 -m checks.gap_fill_krasnoe
```
