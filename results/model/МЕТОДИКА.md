# Суточный прогноз температуры для станций из каталога

Модель оценивает среднесуточную температуру воздуха на следующий календарный день. Для каждой станции прогноз рассчитывается по её собственным наблюдениям и широте из паспорта, если она указана. Общие коэффициенты позволяют рассчитать прогноз для новой станции сразу после регистрации.

## Модель

Линейная регрессия оценивает поправку к правилу «завтра как сегодня». Поправка складывается из взвешенного изменения температуры за два последних дня и плавной сезонной составляющей. Фаза синусоиды отсчитывается от северного зимнего солнцестояния и учитывает число суток в календарном году. Множитель сезонной составляющей равен отношению синуса широты станции к синусу широты района заповедника, с ограничением от −1 до +1. Это меняет знак между полушариями, ослабляет поправку в сторону экватора и ограничивает её за пределами широты обучающего набора. На экваторе и без координат действует только поправка по наблюдаемому изменению температуры.

Обучение использует архив организаторов и построенные из него пригодные суточные средние `t_air`. Пример включает цель и два предыдущих календарных дня. Для каждой пары «цель и предыдущие сутки» все три значения должны быть пригодными. Потеря каждой станции получает одинаковый общий вес, чтобы длинный ряд АМЕ-60 не подавлял ряды Кр1 и Кр2. Коэффициенты сохраняются по состоянию на начало календарного года. Для любого прогноза выбираются коэффициенты, рассчитанные до даты цели. У самого раннего периода до 1993 года ещё нет снимка, поэтому для этих дат доступно правило «как сегодня». Последние общие коэффициенты обучены на 10 094 примерах по 31.12.2025 включительно.

## Проверка на отложенных датах

Средняя абсолютная ошибка (MAE) рассчитана на одних и тех же датах для модели и правила «как сегодня». Для каждой станции тестовый период — последний календарный год её архива. Входные температуры за прошедшие сутки могут поступать в течение теста. Коэффициенты фиксируются до его начала.

| Станция | Фактические даты теста | Суток теста | MAE модели, °C | MAE «как сегодня», °C |
|---|---|---:|---:|---:|
| АМЕ-60 | 07.01.2021–05.11.2021 | 249 из 365 | 1,850 | 1,887 |
| Кр1 · поляна | 01.01.2025–31.12.2025 | 365 из 365 | 1,723 | 1,726 |
| Кр2 · поле | 01.01.2025–31.12.2025 | 353 из 365 | 1,696 | 1,706 |

Снимок для 2021 года успел получить наблюдения только АМЕ-60. Для 2025 года в обучении есть 8 249 примеров АМЕ-60, 639 Кр1 и 488 Кр2. Пропуски в тестовых датах АМЕ-60 и Кр2 исключены.

## Проверка переноса на исключённую станцию

Для каждой строки из обучения полностью исключена станция, на которой рассчитывается MAE. Для оставшихся станций в обучение входят только даты до начала тестового периода.

| Исключённая станция | Станции для обучения | Суток теста | MAE модели, °C | MAE «как сегодня», °C |
|---|---|---:|---:|---:|
| АМЕ-60 | Ко времени теста наблюдений других станций ещё нет | — | — | — |
| Кр1 · поляна | АМЕ-60, Кр2 | 365 из 365 | 1,722 | 1,726 |
| Кр2 · поле | АМЕ-60, Кр1 | 353 из 365 | 1,695 | 1,706 |

На Кр1 и Кр2 переносимая модель снизила MAE соответственно примерно на 0,004 и 0,011 °C. Обе станции находятся в одном районе. Проверка указала на небольшую разницу с базой для этих станций. Точность в других климатах и будущем требует собственных проверок. Географическая поправка задаёт направление годового цикла, а её численный коэффициент оценён на местном архиве.

## Работа с наблюдениями

- Выберите станцию из каталога. Режим наблюдений станции использует исходный архив и подтверждённые файлы. Средние проходят те же правила качества и покрытия, что и графики. Замещённые оценки, искусственные строки и черновики пропускаются. Если пригодная температура отсутствует хотя бы за один из двух последовательных дней, модель возвращает сообщение с датами.
- В ручном режиме введите средние за два последовательных завершившихся дня. Этот режим доступен сразу после регистрации станции. Для границы суток используется часовой пояс паспорта, если он сохранён. По умолчанию действует московское время для архивных станций и UTC для зарегистрированных. Интерфейс показывает календарь и последнюю завершившуюся дату ручного ввода. Оценку покрытия ручных наблюдений выполняет пользователь.
- Подтверждённые значения проверяются по часовому поясу исходного файла, если он указан при обработке. Для источников без пояса применяется тот же календарь, что и при ручном вводе. Если в суточном среднем участвуют источники с разными поясами, дата допускается после окончания суток во всех этих поясах. Временные метки и группировка исходных наблюдений сохраняются.
- Дата источника относится к последнему дню наблюдений. Целевая дата наступает на следующий календарный день. В архивном расчёте фактическое значение цели, если оно есть, показывается для сравнения с оценкой.

```sh
python3 station_model.py
python3 -m unittest discover -s checks -p test_station_model.py
```

Обучение использует стандартную библиотеку Python и сверяет контрольные суммы архива и рабочей базы. Коэффициенты, даты обучения и обе группы метрик доступны в [temperature.json](temperature.json). Интерфейс прогноза доступен на `/model`, каталог модели — на `/api/model/catalog`.
